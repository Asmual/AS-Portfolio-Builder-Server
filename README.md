# AS-Portfolio-Builder-Server

Backend API server for **AS Portfolio Builder** — Multi-Tenant SaaS Platform.

## Tech Stack
- Node.js & TypeScript
- Express.js
- Supabase PostgreSQL (Prisma ORM ready)
- Zod Request Validation
- Modular Service/Controller Architecture

## Getting Started
```bash
pnpm install
pnpm dev
```
Server runs on `http://localhost:5000` with health check at `/api/v1/health`.
